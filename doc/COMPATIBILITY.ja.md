# ImageFlux / OpenFlux 機能対応表

[English](COMPATIBILITY.md) | 日本語

[ImageFlux の画像変換機能](https://console.imageflux.jp/docs/) と、本リポジトリ (OpenFlux: Cloudflare Workers + Cloudflare Images) の対応状況です。

凡例:

- ✅ 対応
- ⚠️ 一部対応・挙動に差異あり
- ❌ 非対応
- — 該当なし

「検証」列の意味:

- **実測一致**: demo.imageflux.jp の実際の出力を計測した値と一致することをユニットテストで確認済み
- **ローカル確認**: `cf dev` (ローカル版 Images) で動作を確認済み
- **要本番確認**: ローカル版 Images では再現されない処理を使うため、本番の Cloudflare Images (`pnpm dev:remote` またはデプロイ) での確認が必要

最終更新: 2026-10-09

## 概要

|                       | ImageFlux の機能のうち                                                                                                                                           |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ✅ 対応               | 拡大・縮小、クリッピング、回転・反転、フィルタ、画像オーバーレイ、クリッピングマスク、出力 (MP4 以外)、URL 署名、配信有効期限、オリジン設定、キャッシュ管理 API  |
| ⚠️ 一部対応・差異あり | テキストオーバーレイ (フォント・文字組みの一部)、Exif Orientation の既定の扱い、`lossless` `o` `s`、Host ヘッダの指定、署名ヘッダ名 (`X-OpenFlux-Signature`)     |
| ❌ 非対応             | MP4 出力、テキストの `dir` `wrap` `ellipsize` `justify` と Noto フォールバック、新しいキャッシュ API (旧 API 互換のみ実装)、WordPress プラグイン、ライブ動画配信 |

### テキストオーバーレイの内訳

テキストの描画 (`text()`) はローカル版 Images では動かないため、描画結果はすべて要本番確認です。
「実測一致」は配置の計算式を demo.imageflux.jp の実測値でテストしていることを表します。

| パラメータ                        | 内容                                     | ImageFlux             | OpenFlux | 検証                  | 備考                                                                                                                                                    |
| --------------------------------- | ---------------------------------------- | --------------------- | -------- | --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `text`                            | 描画するテキスト (改行 `%0A` を含む)     | ✅                    | ✅       | 要本番確認            | 改行ごとに 1 行ずつ描画して並べる                                                                                                                       |
| `font`                            | フォント                                 | ✅ モリサワフォント等 | ⚠️       | 要本番確認            | モリサワフォントは使えない。設定の `fonts` にフォントファイル (TTF/OTF/WOFF/WOFF2) の URL を登録する                                                    |
| `font=(名前,instance=…)`          | バリアブルフォントの名前付きインスタンス | ✅                    | ⚠️       | 要本番確認            | `fonts` に `"名前:インスタンス名"` のキーでフォントファイルを登録したものだけ使える                                                                     |
| `font=(名前,var=タグ:値)`         | バリアブルフォントの可変軸               | ✅                    | ⚠️       | 要本番確認            | `fonts` に `"名前:wght=700"` (複数軸はタグ順に `,` 区切り) のキーで登録した値の組み合わせだけ使える。任意の値は不可                                     |
| 未登録のフォント・インスタンス    |                                          | —                     | ⚠️       | —                     | 既定フォントで描画し `X-OpenFlux-Ignored` で通知 (`strict: true` なら 400)                                                                              |
| フォールバック (Noto)             | 収録外の文字                             | ✅                    | ❌       | —                     | 文字ごとの収録判定ができないため                                                                                                                        |
| `size`                            | フォントサイズ                           | ✅                    | ⚠️       | 要本番確認            | ImageFlux も Cloudflare も pt 単位と見られるが、描画サイズの一致は未確認                                                                                |
| `f`                               | 文字色                                   | ✅                    | ✅       | 要本番確認            |                                                                                                                                                         |
| `b`                               | 描画領域の背景色                         | ✅                    | ✅       | 要本番確認            |                                                                                                                                                         |
| `w` `h`                           | 描画領域のサイズ                         | ✅                    | ✅       | 要本番確認            | はみ出しは切り取り                                                                                                                                      |
| `align`                           | 左・中央・右そろえ                       | ✅                    | ✅       | 実測一致 / 要本番確認 | 行ごとに適用                                                                                                                                            |
| `linespacing`                     | 行間                                     | ✅                    | ✅       | 実測一致 / 要本番確認 | 0 なら自然な行送り、それ以外は自然な行送り × 2 × linespacing (負なら上に重なる)。自然な行送りは描画した行の高さから求めるため、フォントによって差が出る |
| `strike`                          | 取り消し線                               | ✅                    | ✅       | 実測一致 / 要本番確認 | 各行の高さの 60% の位置に、行の高さの約 1/20 の太さで文字色の線を引く (Ryumin R-KL で実測)                                                              |
| `dir`                             | 書字方向                                 | ✅                    | ❌       | —                     |                                                                                                                                                         |
| `wrap` `ellipsize` `justify`      | 折り返し・省略記号・均等割付             | ✅                    | ❌       | —                     | 文字幅を計測できないため                                                                                                                                |
| `oc` `ocr` `og` `or`              | 描画領域の切り抜き・回転                 | ✅                    | ✅       | 要本番確認            |                                                                                                                                                         |
| 位置指定 (`x` `y` `xr` `yr` `lg`) |                                          | ✅                    | ✅       | 実測一致              | 画像オーバーレイと同じ計算                                                                                                                              |
| `mask`                            | テキストをマスクとして使う               | ✅                    | ✅       | 要本番確認            |                                                                                                                                                         |
